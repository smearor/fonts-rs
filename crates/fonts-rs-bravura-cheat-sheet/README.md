# fonts-rs-bravura-cheat-sheet

Bravura SMuFL music notation cheat sheet application.

## Overview

A GTK4 application that displays all Bravura SMuFL glyphs with their
names and codepoints, serving as a reference and demo for the
`fonts-rs-bravura` crate.

## Features

- **`gtk`** (default) - GTK4 application

## Usage

```bash
cargo run -p fonts-rs-bravura-cheat-sheet
```
