# fonts-rs-fourteen-segment-cheat-sheet

DSEG14 fourteen-segment display font cheat sheet application.

## Overview

A GTK4 application that displays all DSEG14 glyphs with their names and
codepoints, serving as a reference and demo for the
`fonts-rs-fourteen-segment` crate.

## Features

- **`gtk`** (default) - GTK4 application

## Usage

```bash
cargo run -p fonts-rs-fourteen-segment-cheat-sheet
```
