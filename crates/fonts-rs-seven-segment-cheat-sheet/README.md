# fonts-rs-seven-segment-cheat-sheet

DSEG7 seven-segment display font cheat sheet application.

## Overview

A GTK4 application that displays all DSEG7 glyphs with their names and
codepoints, serving as a reference and demo for the
`fonts-rs-seven-segment` crate.

## Features

- **`gtk`** (default) - GTK4 application

## Usage

```bash
cargo run -p fonts-rs-seven-segment-cheat-sheet
```
