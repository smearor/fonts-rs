Noto Emoji cheat sheet application.

## Overview

A GTK4 application that displays all Noto Emoji glyphs with their keywords
and categories, serving as a reference and demo for the `fonts-rs-noto-emoji`
crate.

## Features

- **`gtk`** (default) - GTK4 application
- **`metadata`** (default) - Emoji keywords and categories for search

## Usage

```bash
cargo run -p fonts-rs-noto-emoji-cheat-sheet
```
