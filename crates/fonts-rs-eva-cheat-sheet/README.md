Eva Icons cheat sheet application.

## Overview

A GTK4 application that displays all Eva icons with their keywords,
serving as a reference and demo for the `fonts-rs-eva` crate.

## Features

- **`gtk`** (default) - GTK4 application
- **`metadata`** (default) - Icon keywords for search (Eva ships no
  categories or aliases)

## Usage

```bash
cargo run -p fonts-rs-eva-cheat-sheet
```
