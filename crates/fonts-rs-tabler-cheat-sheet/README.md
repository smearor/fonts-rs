Tabler Icons cheat sheet application.

## Overview

A GTK4 application that displays all Tabler icons with their keywords,
categories, and aliases, serving as a reference and demo for the
`fonts-rs-tabler` crate.

## Features

- **`gtk`** (default) - GTK4 application
- **`metadata`** (default) - Icon keywords, categories, and aliases for search

## Usage

```bash
cargo run -p fonts-rs-tabler-cheat-sheet
```
