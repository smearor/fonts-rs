# fonts-rs-dicefont-cheat-sheet

Dicefont cheat sheet application.

## Overview

A GTK4 application that displays all Dicefont die face glyphs with
their names and codepoints, serving as a reference and demo for the
`fonts-rs-dicefont` crate.

## Features

- **`gtk`** (default) - GTK4 application
- **`metadata`** (default) - Die-type categories
  (d2/d4/d6/d8/d10/d12/d20/fudge) for the category sidebar and search

## Usage

```bash
cargo run -p fonts-rs-dicefont-cheat-sheet
```
