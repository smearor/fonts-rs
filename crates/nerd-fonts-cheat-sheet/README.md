Nerd Fonts cheat sheet application.

## Overview

A GTK4 application that displays all Nerd Font icons with their names and
codepoints, serving as a reference and demo for the `nerd-fonts-rs` crate.

## Features

- **`gtk`** (default) - GTK4 application
- **`embed-fonts`** (default) - Embedded font files
- **`metadata`** (default) - Icon keywords and categories for search

## Usage

```bash
cargo run -p nerd-fonts-cheat-sheet
```
