# fonts-rs-doto-cheat-sheet

Doto dot-matrix font cheat sheet application.

## Overview

A GTK4 application that displays all Doto glyphs with their names and
codepoints, serving as a reference and demo for the `fonts-rs-doto`
crate.

## Features

- **`gtk`** (default) - GTK4 application

## Usage

```bash
cargo run -p fonts-rs-doto-cheat-sheet
```
