Noto Emoji color-flags font integration for GTK 4 and pixel-drawing.

Provides glyph name resolution, GResource registration, and codepoint lookup for the color-flags variant of the Noto Emoji font family - Google’s COLRv1 vector emoji font (Noto-COLRv1, including flag emoji) covering all Unicode emoji codepoints with semantic names from CLDR annotation data. GResource SVGs ship full-color artwork regardless of variant.

§Quick Start

use fonts_rs_noto_emoji_color_flags::NotoEmoji;

// Call once at startup before using any glyphs
if let Err(e) = NotoEmoji::install() {
    eprintln!("Failed to install font: {e}");
}

Then resolve glyph names to Unicode codepoints:

use fonts_rs_noto_emoji_color_flags::NotoEmoji;

let codepoint = NotoEmoji::codepoint("grinning-face");
