Nerd Font Cheat Sheet application.

Browse all available Nerd Font icons with a search filter. Displays each icon with its Unicode codepoint, CSS class name, keywords, and categories. Search covers icon names, keywords, categories, and aliases. Click an icon to open a detail sidebar.

Run with:

cargo run --example cheat_sheet --features gtk,render,embed-fonts,metadata
