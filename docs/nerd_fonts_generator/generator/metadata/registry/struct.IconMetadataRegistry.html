Struct IconMetadataRegistry 

Source 
pub struct IconMetadataRegistry {
    sources: Vec<Box<dyn IconMetadataSource>>,
}
Expand description

Aggregates multiple IconMetadataSource implementations.

The generator queries this registry to resolve keywords and categories for any Nerd Font icon name. Sources are tried in order; the first matching source (by prefix) wins.

pub fn alias_for(&self, nf_icon_name: &IconName) -> Option<IconName>

Resolves the canonical NF icon name for an alias.

Returns the full Nerd Font icon name (e.g. "nf-fa-gear-symbolic") if the given name is an alias, or None if no source matches or the name is not a known alias.

Source

pub fn all_aliases(&self) -> Vec<(IconName, IconName)>

Returns all aliases from all registered sources as (alias_nf_name, canonical_nf_name) pairs.

Each pair uses full Nerd Font icon names with -symbolic suffix. Names are validated and normalized via IconName::parse. Duplicate alias keys (after normalization) are deduplicated.
