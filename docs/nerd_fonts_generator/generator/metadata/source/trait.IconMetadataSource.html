Expand description

Trait for upstream icon metadata providers.

Each implementation parses upstream metadata files and provides keyword and category lookups for individual icons by their upstream name (without Nerd Font prefix or -symbolic suffix).

Extracts the upstream icon name from a Nerd Font icon name.

Strips the Nerd Font prefix and -symbolic suffix. Returns None if the name does not match this source’s prefix or is empty after stripping.
