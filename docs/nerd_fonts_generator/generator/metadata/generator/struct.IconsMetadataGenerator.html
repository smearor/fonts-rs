pub struct IconsMetadataGenerator<'a> {

}
Expand description

Generates phf::Map constants for icon keywords, categories, and aliases.

Keywords come from upstream metadata sources when available, and from name segments for other icon sets. Categories come from upstream metadata when available, and from the icon set prefix for others. Aliases come from upstream metadata sources.
