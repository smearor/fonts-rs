Shared data types for Nerd Font icon handling.

Provides common types used across the nerd-fonts ecosystem: CodePoint, IconName, IconSet, etc.

Generic types (CodePoint, ResourcePath, GlyphEntry) are re-exported from fonts-rs-model. Nerd Font specific types (IconName, IconSet) remain in this crate.
