Struct NerdFontsConfig

pub struct NerdFontsConfig;
Expand description

Build-time configuration for the Nerd Fonts font family.

Supplies the constants for the generic IconName pipeline: the nf- icon prefix and IconSet-based validation.

const CODEPOINT_RANGES: &[CodePointRange]

Nerd Fonts uses two disjoint ranges:

  • BMP (U+0000–U+FFFF): legacy icon codepoints including the PUA range U+E000–U+F8FF.
  • Supplementary PUA (U+F0001–U+10FFFF): additional icon codepoints that don’t fit in the BMP PUA (Nerd Fonts 3+).
