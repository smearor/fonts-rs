Emoji metadata: keywords and categories for search functionality.

Provides keyword and category lookup for Noto Emoji glyphs, enabling search and filtering beyond simple name matching.

Keywords are sourced from CLDR annotation data (default field). Categories are sourced from Unicode emoji-test.txt (group field).

This module is only available when the metadata feature is enabled.
