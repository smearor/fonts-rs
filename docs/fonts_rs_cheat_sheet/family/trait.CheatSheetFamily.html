Expand description

Family-specific data surface for the cheat sheet UI.

Implement once per font family; crate::run builds the complete application from these hooks. The associated Name type is the family’s glyph name - IconName for icon fonts, String or GlyphName<F> for others.

§Examples

ⓘ
struct NotoEmojiSheet;

impl CheatSheetFamily for NotoEmojiSheet {
    type Name = String;
    // ...
}

fn main() -> miette::Result<glib::ExitCode> {
    fonts_rs_cheat_sheet::run::<NotoEmojiSheet>()
}

fn ordering() -> Option<&'static dyn GlyphOrdering>

Optional canonical ordering contract for the family.

Families with an upstream-curated glyph order (e.g. emoji picker ordering) return their GlyphOrdering implementation here; None (the default) keeps the alphabetical grid.

Opting in enables, per glyph name, in the cheat sheet UI:

  • Picker-order grid sort via order_index (search results and all_glyphs in picker order),
  • group jump-list dropdown and a group label in the detail sidebar via group_labels/group,
  • variant collapsing in the browse grid via collapse_variants/base_of (opt-in per family - emoji tones collapse, style families do not) plus a “Variants” section and “Variant of” back-link in the sidebar via alternates/base_of,
  • default-tone picking via tone_group: a chosen alternate position is stored per tone group and the browse grid swaps base cells to that tone.
Source

fn glyph_icon_name(_name: &Self::Name) -> Option<String>

Icon-theme name for a glyph, rendered via an image widget in grid cells instead of a text label.

None (the default) renders the codepoint character as text. Return Some for families that register full-color SVG glyphs in the GtkIconTheme - e.g. emoji fonts whose bundled TTF family name would otherwise resolve to a system font.
