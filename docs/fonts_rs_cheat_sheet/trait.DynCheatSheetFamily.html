Expand description

Object-safe runtime view of a cheat-sheet family - the string-typed counterpart of CheatSheetFamily for multi-family hosts (run_multi, the fonts-rs facade CLI).

Every member mirrors its CheatSheetFamily counterpart; glyph names are carried as String instead of the family’s typed Name. The bridge between the two is FamilyAdapter, which re-enters the typed world via parse_name.

Concrete XSheet types live downstream of this crate, so the multi-family host cannot dispatch over a closed enum - the object surface is the shared point both paths use.
