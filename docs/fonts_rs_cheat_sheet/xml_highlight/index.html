Lightweight XML syntax highlighting for the SVG code block.

A full editor widget (gtksourceview) would pull in a heavy dependency chain for a read-only preview. Instead a small byte scanner marks tag names, attributes, delimiters and comments with [gtk4::TextTag]s - enough to make raw SVG XML readable.

tokenize 🔒
Scans xml and yields (start, end, token) byte ranges for every markup element. Text content between tags is skipped - SVG output never contains a raw < outside markup, so plain < always opens a tag, comment or prolog.
