Icon Set Builder - cross-family glyph selection that emits an icons.toml for [IconSetBuild].

The library holds the GTK-free pieces: the IconSource registry (which crates feed [[iconset.sources]]), the IconSelection model (picked upstream icons + renames per source, live exported-name collision detection), the Scaffold paste block, and the Preview runner driving IconSetBuild::preview over a temp dir.

The fonts-rs-iconset-builder binary wraps these in a combined cross-family browser: one grid over the icon-capable cheat-sheet families, selection sidebar, settings pane, Save/Copy/Preview.
