pub trait FontFamilyMarker: Sealed { }
Expand description

Marker trait for font family identity.

Implemented by each font family crate as a zero-sized enum (e.g. SevenSegment, Barcode). Used as the phantom type parameter in GlyphName<F> to ensure type safety between font families at compile time.

Application crates may also implement it for generated icon-set markers (see fonts-rs-generator’s IconSetBuild) — the public sealed re-export makes that possible.

For the runtime API surface (glyph maps, capability traits), see FontFamily.

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
