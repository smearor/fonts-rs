Facade crate for the fonts-rs workspace.

One dependency, feature-selected font families. Every enabled family is reachable under its own module alias (fonts_rs::lucide::…), and its marker type plus name alias are additionally re-exported at the crate root (fonts_rs::Lucide, fonts_rs::LucideIconName) - the types most call sites name. fonts_rs::model is always available.

[dependencies]
fonts-rs = { version = "0.5", features = ["lucide", "doto"] }

Capabilities - forwarded to every enabled family that has them:

FeatureSemantics
gtk (default)GtkFont/IconThemeFont, GTK rendering
renderab_glyph software rasterization
metadatakeyword/category/alias metadata

Groups - icons, emoji, segment, barcode, all.

Binary - gui builds the fonts-rs multi-family cheat sheet (cargo install fonts-rs --features gui); gui-core plus selected sheet-* features installs a subset.

default-features = false produces a genuinely GTK-free build: family deps are declared without default features.
