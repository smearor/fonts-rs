Struct NotoEmojiDefinition 

Source 
pub struct NotoEmojiDefinition;
Expand description

Build-time configuration for the Noto Emoji font family.

Implements FontDefinition to plug into the generic FontDefinition::export_glyphs pipeline.

Note: The build script typically uses ExportConfig::export_glyphs_by_name_map with CLDR annotation data instead of the generic pipeline, because Noto Emoji glyph names are uniXXXX format and require CLDR lookup for semantic names. This definition still provides the constants and type information.
