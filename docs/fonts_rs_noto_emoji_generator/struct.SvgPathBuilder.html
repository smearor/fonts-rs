Struct SvgPathBuilder 

pub struct SvgPathBuilder {
    pub path: String,
    bbox: BoundingBox<f32>,
}
Expand description

SVG path data builder implementing skrifa::outline::OutlinePen.

Collects SVG path commands (M, L, Q, C, Z) as the font outline is traversed, then exposes the accumulated path string. Also tracks the bounding box of all points visited.
