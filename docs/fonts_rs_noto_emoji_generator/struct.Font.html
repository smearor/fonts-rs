Struct Font 

pub struct Font<'a> {
    inner: FontRef<'a>,
}
Expand description

A newtype wrapper around skrifa::FontRef providing font utility methods.

Implements Deref to FontRef so all underlying skrifa methods (e.g. glyph_names(), outline_glyphs()) remain accessible.

pub fn glyph_to_svg_full_height(&self, glyph_id: GlyphId) -> Option<Svg>

Generate SVG content for a glyph using the font’s full height for the viewBox.

Unlike glyph_to_svg, which crops the viewBox to the glyph’s bounding box, this method uses the font’s ascent/descent for the vertical extent. This ensures that glyphs which only occupy part of the font’s height (e.g. lowercase letters in a 7-segment display font) are not scaled up disproportionately when rendered at a fixed icon size.

The glyph is horizontally positioned at its natural x offset within the font’s coordinate space.

pub fn glyph_to_svg_full_height_at( &self, glyph_id: GlyphId, location: LocationRef<'_>, ) -> Option<Svg>

Generate SVG content for a glyph at the given variation location, using the font’s full height for the viewBox.

Like glyph_to_svg_full_height but renders the glyph at the specified variation axis location.
