fn is_flag_emoji(codepoints: &[CodePoint]) -> bool
Expand description

Returns true if the codepoint sequence is a flag emoji.

Covers regional-indicator pairs (e.g. 🇩🇪 = U+1F1E9 U+1F1EA) and subdivision flags, which start with U+1F3F4 (waving black flag) followed by tag characters (e.g. 🏴󠁧󠁢󠁥󠁮󠁧󠁿 England).
