Expand description

Self-contained inline-SVG HTML export.

The only requirement is IconThemeFont::glyph_svg, so fontless icon families (e.g. Lucide) can implement this trait without a TTF. Families that also ship a TTF implement HtmlExport instead, which adds @font-face support on top.

This trait is implemented explicitly per family (opt-in via the html_svg capability of impl_font_family!), unlike HtmlExport which additionally requires a loadable font.
