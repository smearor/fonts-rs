LucideMetadata
lucide_metadata provider: merges the per-icon {dir}/*.json files of the upstream checkout into one {stem: {field: value}} map, projecting each entry onto the declared with.fields in order. Used for lucide’s icons.json (with.fields = ["tags", "categories"], dropping $schema/contributors/ use-cases) and categories.json (["title", "icon"]).
MergedObjects 🔒
The merged top-level object serialized in insertion order - the vendored files order keys by upstream filename, not by stem.
OrderedFields 🔒
A JSON object serialized with its declared field order - the vendored files keep e.g. tags before categories while serde_json::Map would sort keys alphabetically.
