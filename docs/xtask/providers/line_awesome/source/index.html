icon_classes
Extracts .{class}... { content: "\fXXX"; } rules and returns the (class, codepoint) pairs whose class carries prefix (la- / fa-). For compound selectors the icon class is the last prefixed token (.la.la-address-book-o -> la-address-book-o).
parse_css_escape 🔒
Reads the content: "\fXXX" escape out of a declaration block or scss value.
parse_variables
Parses $la-{name}: \fXXX; declarations into a name -> codepoint map. Non-icon variables (paths, colors, sizes) carry no \f escape and are ignored.
svg_stems
Lists the sorted file stems of every *.svg directly below dir.
