collect_matching 🔒
Recursively collects (checkout-relative path, absolute path) pairs matching glob but not excludes below dir.
copy_dedup 🔒
Copies source_path to target_path unless another source file with identical content was already materialized there (flattened directory dedup). Conflicting contents for the same target are an error.
copy_file 🔒
Copies source (checkout-relative file) to target (crate-relative file) and records it.
dedup_target 🔒
Claims target for source/sha in the dedup map. Returns true when the caller must write the file, false when an identical artifact already materialized there; conflicting content for the same target is an error.
fetch_url 🔒
Materializes a url artifact: fetches the URL via the shared fetch cache and writes it verbatim to target (a single file). The URL itself is recorded as the artifact source.
materialize 🔒
Materializes one [[artifacts]] entry: a 1:1 file copy, or a flattened glob copy of a directory.
materialize_archive 🔒
Materializes a url+source artifact: fetches an archive (.tgz/.tar.gz/.zip) and extracts source - a member file for 1:1 copies, or a member directory globbed with pattern/exclude and flattened into target like a checkout directory. Provenance is url#member.
remove_stale 🔒
Deletes files recorded in the previous lockfile that are no longer produced, so removed upstream artifacts do not linger.
rewrite_manifest_ref 🔒
Rewrites ref = "<old>" to ref = "<new>" in upstream.toml, replacing the whole line (stale pin annotations are dropped - the bump is reviewed in the commit diff anyway).
write_file 🔒
Writes content to path, creating parent directories.
