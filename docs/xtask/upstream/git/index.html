sparse_paths
Returns the sorted, deduplicated non-cone sparse-checkout pattern set for a manifest. Artifact sources with a glob pattern yield source/pattern (so e.g. assets/**/ic_fluent_*_24_regular.svg checks out only the 24px slices of a giant tree); plain sources match the file itself or, for directories, the whole subtree. extra covers license sources and explicit sparse entries. Artifact exclude globs become !-negated patterns so excluded blobs are not checked out either.
version_key 🔒
Version key for tag sorting: vX.Y.Z... → [X, Y, Z]; None for non-numeric tags (pre-releases, named tags). Requires at least a major.minor pair so v1 does not outrank real releases.
