Blobmoji color-noflags font integration for GTK 4 and pixel-drawing.

Provides glyph name resolution, GResource registration, and codepoint lookup for the color-noflags variant of the Blobmoji font family - a community-maintained emoji font recreating Google’s classic “blob” emoji style (COLRv1 vector font Noto-COLRv1-noflags, flag emoji filtered out), covering all Unicode emoji codepoints with semantic names from CLDR annotation data. GResource SVGs ship full-color artwork regardless of variant.

§Quick Start

use fonts_rs_blobmoji_color_noflags::Blobmoji;

// Call once at startup before using any glyphs
if let Err(e) = Blobmoji::install() {
    eprintln!("Failed to install font: {e}");
}

Then resolve glyph names to Unicode codepoints:

use fonts_rs_blobmoji_color_noflags::Blobmoji;

let codepoint = Blobmoji::codepoint("grinning-face");
