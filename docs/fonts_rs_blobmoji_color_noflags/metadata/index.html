Emoji metadata: keywords, categories, aliases, and picker ordering.

Provides keyword and category lookup for Blobmoji glyphs, enabling search and filtering beyond simple name matching, plus the canonical emoji picker group ordering.

Keywords are sourced from CLDR annotation data (default field). Categories are sourced from Unicode emoji-test.txt (group field). Aliases are shortcodes (:smile:) and emoticons (:D) from googlefonts/emoji-metadata. Multi-codepoint sequences (ZWJ, keycap, flag) carry no CLDR keywords - the CLDR keyword map is keyed by single codepoints.

Ordering tables (ORDERING, GROUPS, GROUP_OF, ALTERNATES, BASE_OF, SHORTCODES, TONE_GROUP) are generated from emoji_17_0_ordering.json; alternates (skin tones, gender, ZWJ combos) are linked to their base emoji.

This module is only available when the metadata feature is enabled.
