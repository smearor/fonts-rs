Expand description

Runtime access to a font family: metadata and glyph maps.

Implemented once per font crate via impl_font_family!. The core trait is feature-free - pure data access that works without GTK.

const CSS_FONT_FAMILY: &'static str = Self::FAMILY_DISPLAY_NAME

CSS font-family name, e.g. "Libre Barcode Code 39".

Defaults to the display name; override for families whose CSS name differs.

Source

const VARIANTS: &'static [FontVariant] = _

Build-time variant metadata (see FontVariant). Empty for single-font families; lists the shipped TTF variants otherwise. Useful for UIs that offer a variant picker.

Required Associated Types§

Source

type Name: AsRef<str> + FromStr

Typed glyph name of this family (e.g. GlyphName<Code39>, IconName for Nerd Fonts).

FromStr lets implementations construct the typed name from the &'static str stored in the glyph maps; AsRef<str> lets lookup methods accept it alongside plain &str constants.

fn glyph_name(ch: impl Into<CodePoint>) -> Option<Self::Name>

Looks up the typed glyph name for a Unicode codepoint.

Accepts both char and CodePoint via Into<CodePoint>.

Source

fn codepoint(name: impl AsRef<str>) -> Option<CodePoint>

Looks up the codepoint for a glyph name.

Accepts &str, String, and the typed Self::Name via AsRef<str> - both constants::UNI002A and GlyphName<F> work.

Source

fn all_glyphs() -> impl Iterator<Item = (CodePoint, Self::Name)>

Iterates all (codepoint, glyph_name) pairs.

Yields the typed Self::Name, consistent with glyph_name. Use AsRef<str> on the name when plain &str access is enough.

Provided Methods§

Source

fn glyph_count() -> usize

Returns the number of glyphs in this family.

Default: all_glyphs().count() - O(n). Implementations backed by a phf::Map override this with map.len() - O(1).
