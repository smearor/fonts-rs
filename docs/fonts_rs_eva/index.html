Eva Icons font integration for GTK 4 and pixel-drawing.

Provides icon name resolution, GResource registration, and codepoint lookup for the Eva Icons font family - both upstream styles in one export: ~490 fill icons (eva-{name}-symbolic) plus ~490 outline icons (eva-{name}-outline-symbolic), sharing the single webfont TTF’s codepoint space.

Keyword metadata (metadata feature) is sourced from upstream icons-tags.json - the search tags powering the official eva-icons.com cheat sheet.

§Quick Start

use fonts_rs_eva::Eva;

// Call once at startup before using any icons
if let Err(e) = Eva::install() {
    eprintln!("Failed to install font: {e}");
}

Then resolve icon names to Unicode codepoints:

use fonts_rs_eva::Eva;

let codepoint = Eva::codepoint("eva-home-symbolic");
