Icon metadata: keywords, style categories and ordering.

Provides keyword lookup for Eva icons, enabling search beyond simple name matching - e.g. “alarm” finds eva-bell-symbolic and eva-clock-symbolic.

Keywords are sourced from upstream icons-tags.json (converted from icons-tags.ts, the search tags powering the official eva-icons.com cheat sheet). Categories carry the style (“fill” / “outline”); Eva ships no aliases.

[GlyphOrdering] groups glyphs by style and pairs eva-{name}-outline-symbolic onto its fill base eva-{name}-symbolic - the link powers the detail sidebar’s Variants section and sorts each outline glyph next to its fill base (styles never collapse).

This module is only available when the metadata feature is enabled.
