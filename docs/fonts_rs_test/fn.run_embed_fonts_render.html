Expand description

Runs a GTK app rendering text with ab_glyph software rendering.

Resolves the family’s ab_glyph font via F::font(), renders the given text into an RGBA pixel buffer, wraps it as a GDK memory texture, and displays it in a Picture widget.

§Type Parameters

  • F: Font family implementing SoftwareRender.

§Parameters

  • app_id: Unique GTK application ID.
  • window_title: Window title text.
  • text: Text to render.
  • font_size: Font size in pixels.

§Errors

Returns an error if GTK init fails or the font is not available.
