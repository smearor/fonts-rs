Expand description

Runs a GTK app displaying SVG glyphs from GResource as textures.

Registers the font’s GResource bundles via F::ensure_registered and displays the first few glyphs as Picture widgets loaded via F::glyph_svg.

§Type Parameters

  • F: Font family implementing IconThemeFont.

§Parameters

  • app_id: Unique GTK application ID.
  • window_title: Window title text.
  • glyphs: Slice of (CodePoint, glyph_name) pairs to display. The name accepts &str, String, and the typed F::Name (GlyphName<F> / IconName) via AsRef<str>.

§Errors

Returns an error if GTK init or GResource registration fails.
