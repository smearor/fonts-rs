Expand description

Runs a GTK app displaying font glyphs as GtkIconTheme icons.

Registers the font’s GResource bundles via F::ensure_registered, adds the family’s icon resource path to GtkIconTheme via F::install_icon_theme, and displays each glyph as a GtkImage resolved by its icon name.

§Type Parameters

  • F: Font family implementing [IconThemeFont].

§Parameters

  • app_id: Unique GTK application ID.
  • window_title: Window title text.
  • icons: Slice of (icon_name, label) pairs to display. Both accept &str, String, and the typed F::Name (GlyphName<F> / IconName) via AsRef<str>.

§Errors

Returns an error if GTK init or GResource registration fails.
