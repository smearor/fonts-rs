Creates and runs a GTK application.

Initializes GTK, creates an Application with the given app_id, connects build_ui to the activate signal, and runs the app.

The app runs with [ApplicationFlags::NON_UNIQUE]: examples are demos, so every process must be a real instance. With the default single-instance behavior a second launch would only forward activate to the running process over D-Bus and exit - the running instance would then open another window with its own (stale) embedded font variant instead of the newly built one.

§Errors

Returns an error if GTK initialization fails.
