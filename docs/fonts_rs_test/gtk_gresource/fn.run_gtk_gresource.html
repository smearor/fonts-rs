pub fn run_gtk_gresource<F: PangoFont>(

    window_title: &str,
    text: &str,
) -> Result<ExitCode>
Expand description

Runs a GTK app loading a TTF font from GResource and rendering text.

Registers the font’s GResource bundles via F::ensure_registered, loads the TTF into the Pango font map via F::install_pango, and displays the text with a CSS font-family rule using F::CSS_FONT_FAMILY.

§Type Parameters

  • F: Font family implementing [PangoFont].

§Parameters

  • app_id: Unique GTK application ID.
  • window_title: Window title text.
  • text: Text to render.

§Errors

Returns an error if GTK init or GResource registration fails.
