Heroicons integration for GTK 4.

Provides icon name resolution, GResource registration, and codepoint lookup for Heroicons - ~320 hand-crafted icons from the makers of Tailwind CSS.

Heroicons is a fontless icon set: upstream ships only pre-rendered SVGs, no webfont. Glyphs are resolved via GtkIconTheme from the GResource bundle; codepoints are stable hash-of-name PUA allocations. There is no pango, render, or embed-fonts capability - and no html (FontFace); typed inline-SVG HTML export works via HtmlSvgExport.

Four variants are available via Cargo features: outline (default, 24x24 stroke-based), solid (24x24 filled), mini (20x20 filled) and micro (16x16 filled). Icon names are variant-independent (heroicons-{name}-symbolic) - the variant selects which SVG set ships in the GResource.

Keyword metadata (metadata feature) is sourced from the heroicons.com search index; aliases map Heroicons v1 names to their v2 canonical names.

§Quick Start

use fonts_rs_heroicons::Heroicons;

// Call once at startup before using any icons
if let Err(e) = Heroicons::install() {
    eprintln!("Failed to install font: {e}");
}

Then resolve icon names to Unicode codepoints:

use fonts_rs_heroicons::Heroicons;

let codepoint = Heroicons::codepoint("heroicons-star-symbolic");
