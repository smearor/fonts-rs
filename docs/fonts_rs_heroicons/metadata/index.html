Source
Expand description

Icon metadata: keywords, style categories, aliases and ordering.

Provides keyword and alias lookup for Heroicons icons, enabling search beyond simple name matching - e.g. “stars” finds heroicons-sparkles-symbolic.

Data is sourced from the heroicons.com site bundle (keyword map, vendored as resources/metadata/keywords.json) and the iconify heroicons set’s v1→v2 alias table (vendored as resources/metadata/aliases.json). Categories carry the style (“outline” / “solid” / “mini” / “micro”).

[GlyphOrdering] groups glyphs by style and pairs each heroicons-{name}-{style}-symbolic variant onto its outline base heroicons-{name}-symbolic, so the cheat sheet can collapse variants like other style families.

This module is only available when the metadata feature is enabled.
