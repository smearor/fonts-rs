Libre Barcode Code 128 font integration for GTK 4.

Provides glyph name resolution, GResource registration, and codepoint lookup for the Libre Barcode Code 128 font family.

§Quick Start

use fonts_rs_barcode_code128::register_glyphs;

// Call once at startup before using any glyphs
register_glyphs().unwrap();

Then resolve glyph names to Unicode codepoints:

use fonts_rs_barcode_code128::Code128Name;
use fonts_rs_barcode_code128::GlyphNameExt;

let name = Code128Name::new("zero".to_string());
let codepoint = name.codepoint();
