Line Awesome integration for GTK 4.

Hybrid family: the 1,544 vendored upstream SVGs ship in the icon GResource (symbolic-recolorable via currentColor injected at build time) and the three upstream la-{regular-400,solid-900, brands-400}.ttf webfonts ship for pango, html (@font-face) and render (pixel-drawing).

Line Awesome follows the Font Awesome 5 model: regular and solid style variants of an icon share one codepoint - the file stem decides the style (la-{name}-symbolic for regular/brand icons, la-{name}-solid-symbolic for solid). All codepoints are FA5 BMP PUA allocations (U+F000–U+F8FF).

§Quick Start

use fonts_rs_line_awesome::LineAwesome;

// Call once at startup before using any icons
if let Err(e) = LineAwesome::install() {
    eprintln!("Failed to install font: {e}");
}

Then resolve icon names to Unicode codepoints:

use fonts_rs_line_awesome::LineAwesome;

let codepoint = LineAwesome::codepoint("la-adjust-symbolic");
