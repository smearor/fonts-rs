Font loaders for Line Awesome software rendering.

The three upstream TTF paths are determined at build time by build.rs and exposed via the LINE_AWESOME_{REGULAR,SOLID, BRANDS}_FONT_PATH environment variables for pixel-drawing (ab_glyph). Each face is cached in its own OnceLock.
