Line Awesome codepoint range.

All upstream codepoints are Font Awesome 5 allocations inside the BMP Private Use Area (U+F000–U+F8FF). Style variants (regular / solid / brands) share the codepoint of their icon name - unlike Fluent there is no Supplementary PUA-A allocation.
