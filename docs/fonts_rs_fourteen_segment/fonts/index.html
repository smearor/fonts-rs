Font loading with ab_glyph for software rendering.

The DSEG14 font is loaded from disk or embedded via embed-fonts feature and cached in OnceLock for the process lifetime.

The active variant’s TTF path is determined at build time by build.rs and exposed via the DSEG14_FONT_PATH environment variable.
