Fluent UI System Icons integration for GTK 4.

Hybrid family: pre-rendered upstream SVGs of both styles ship in the icon GResource (symbolic-recolorable via currentColor) and the FluentSystemIcons-Regular.ttf webfont ships for pango, html (@font-face) and render (pixel-drawing). Regular codepoints are the real upstream values; filled codepoints are hashed into Supplementary PUA-B (upstream allocates both styles into the same PUA space), stable per icon name.

Both styles export in one build: fluent-{name}-symbolic for regular, fluent-filled-{name}-symbolic for filled. Filled glyphs render via the icon theme / SVG path only - the bundled TTF covers regular.

Deprecated upstream icons (hidden.json: flag-pride, text-color-accent) are excluded from the export. The metadata feature exposes metadata::FluentMetadata with filename-derived keywords and the iconify alias table.

§Quick Start

use fonts_rs_fluent::Fluent;

// Call once at startup before using any icons
if let Err(e) = Fluent::install() {
    eprintln!("Failed to install font: {e}");
}

Then resolve icon names to Unicode codepoints:

use fonts_rs_fluent::Fluent;

let codepoint = Fluent::codepoint("fluent-add-symbolic");
