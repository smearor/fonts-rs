Expand description

Self-contained @font-face HTML export.

Extends HtmlSvgExport with the font-based export mode: the default-variant TTF is embedded via GtkFont::load_font. Families that deliberately avoid @font-face (Nerd Fonts) or ship no TTF at all (fontless icon sets) do not implement this trait - they can still implement HtmlSvgExport alone.

Provided Methods§

fn css_font_face() -> Result<String, FontError>

Returns a @font-face CSS rule embedding the default-variant TTF as a base64 data URI. Low-level building block for custom HTML pages.

§Errors

Returns a FontError if registration, font loading, or reading the temp file fails.
