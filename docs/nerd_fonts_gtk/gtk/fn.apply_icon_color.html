Applies a configured icon color to a GTK Image via a display-scoped CssProvider.

A unique CSS class is added to the icon widget, and a CSS rule targeting only that class is loaded on the display. This follows the GTK 4.10 recommendation to avoid widget-scoped StyleContext::add_provider (deprecated since 4.10).
