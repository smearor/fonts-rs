1//! Custom icon sets - TOML-driven glyph subsets for applications.
2//!
3//! An application declares a minimal icon set in a root-level
4//! `icons.toml` and invokes [`IconSetBuild`] from its `build.rs`:
5//!
6//! ```ignore
7//! fn main() -> miette::Result<()> {
8//!     fonts_rs_generator::IconSetBuild::from_file("icons.toml")?.run()?;
9//!     Ok(())
10//! }
11//! ```
12//!
13//! The build reads the [`IconSetSpec`] (defined in `fonts-rs-model` -
14//! the schema is shared with authoring tools), resolves each
15//! `[[iconset.sources]]` table via [`IconSetSourceResolver`], merges the
16//! whitelisted glyphs through `CombinedSource`, and generates the
17//! complete `iconset.rs` module via [`IconSetModuleGenerator`].
18//!
19//! See `concepts/planned/CUSTOM_ICON_SET.md` for the design.
20
