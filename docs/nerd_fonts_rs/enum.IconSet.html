Expand description

Nerd Font icon collections.

Each variant corresponds to a prefix convention used in Nerd Font icon names (e.g. nf-fa-* for Font Awesome, nf-md-* for Material Design). Use IconName::icon_set to determine the collection from a normalized icon name.

pub fn detect(icon_name: &str) -> IconSet

Detects the icon set from a Nerd Font icon name prefix.

Performs a simple prefix match — zero allocation, O(1). The compiler can optimize the match into a jump table.
