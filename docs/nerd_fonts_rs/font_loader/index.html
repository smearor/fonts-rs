Module font_loader 

Source
Expand description

Pango font loading for Nerd Font symbol fonts.

Provides load_fonts which registers the Nerd Font TTF files with the global Pango-Cairo FontMap using add_font_file. This bypasses the GTK4 CSS @font-face parser, which does not reliably load custom fonts.

Fonts are loaded into the global font map, so GTK4 widgets automatically see them without needing a widget reference.
