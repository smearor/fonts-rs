Expand description

Extension trait adding codepoint lookup to IconName.

This trait is implemented in the nerd-fonts-rs crate (not in nerd-fonts-model) because it requires access to the generated codepoint map, which is only available at runtime after build.rs has generated the phf::Map tables.

fn codepoint(&self) -> Option<CodePoint>

Resolves this icon name to its Unicode CodePoint.

Returns None if the icon name is not found in the codepoint map.
