Expand description

Trait for GTK font families with GResource-backed registration.

Implemented by font family marker types via the impl_gtk_font! macro in fonts-rs-generator. Each method is a static (no &self) method callable as e.g. Ean13::register_glyphs().

§Methods

  • register_glyphs: Registers the SVG icon GResource bundle (icons.gresource).
  • register_font: Registers the TTF font GResource bundle (font.gresource). No-op for fonts without a TTF GResource.
  • load_font: Loads the TTF from the GResource into a temp file and returns the path. Returns an error for fonts without a TTF GResource.
  • load_font_from_gresource: Provided helper - shared load_font() body for families whose font GResource bundles one or more TTFs.
  • ensure_registered: Lazy, idempotent registration of all the family’s GResource bundles, cached per family. Called automatically by every capability method.
  • install: Explicit fail-fast setup for application startup.

The 'static supertrait allows ensure_registered to key its global cache by TypeId::of::<Self>().

fn load_font() -> Result<&'static Path, LoadFontError>

Loads the TTF font from the registered GResource into a temp file and returns the path.

The temp file is kept alive for the process lifetime. Use the returned path with FontMapExt::add_font_file.

§Errors

Returns a LoadFontError if the font cannot be registered, looked up, or written.

fn ensure_registered() -> Result<(), FontError>

Idempotent registration of all GResource bundles this family has.

Called lazily by every capability method. The result is cached per family in a global OnceLock keyed by TypeId: subsequent calls return the cached Ok or the cached error. Safe to call from any thread.

A static OnceLock inside this default body would be shared across all impls, so the cache is a HashMap keyed by TypeId::of::<Self>() instead - one entry per family, no macro-generated statics required.

§Errors

Returns the cached FontError if registration failed.

Source

fn install() -> Result<(), FontError>

Explicit fail-fast setup for application startup.

Equivalent to ensure_registered - exists to make intent visible at the call site (Code39::install()? in main()).

§Errors

Returns the cached FontError if registration failed.

fn load_font_from_gresource( resource_path: &str, temp_tag: &str, ) -> Result<&'static Path, LoadFontError>

Extracts one TTF from the registered font GResource into a process-lifetime temp file and returns the cached path.

Shared implementation of the load_font bodies of multi-TTF families: register_font must have succeeded already (the caller’s load_font takes care of it). Results are cached per resource_path; temp_tag (typically env!("CARGO_PKG_NAME") at the call site) namespaces the temp file so faces of different families never collide.

Provided method - implementors are not expected to override it.

§Errors

Returns a LoadFontError if the resource lookup or the temp-file write fails.
