fonts_rs_generator::emoji

Module ordering 

Source
Expand description

Parser and codegen for googlefonts/emoji-metadata ordering files (emoji_*_ordering.json).

The ordering file describes the emoji picker grid layout: an ordered list of groups, each containing emoji entries in picker order with skin-tone/gender alternates, shortcodes (:smile:), and emoticons (:D). It works for any font covering the emoji codepoint ranges (e.g. Noto Emoji, Blobmoji).
