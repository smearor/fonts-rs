fonts_rs_generator::emoji::ordering

Module generator 

Source
Expand description

Codegen for emoji picker ordering data (emoji_*_ordering.json).

EmojiOrderingGenerator takes a parsed EmojiOrdering plus a family-provided sequence→glyph-name resolver and emits the static tables the runtime ordering API needs:

  • ordering.rs - ORDERING: phf::Map<&str, u32> (base name → flat picker index over all ordered base entries)
  • groups.rs - GROUP_ORDER: &[GroupLabel], GROUPS: &[GlyphGroup] (ordered groups with resolved names, alternates inlined after their base) and GROUP_OF: phf::Map<&str, &str> (base and alternate names → group label)
  • alternates.rs - ALTERNATES: phf::Map<&str, &[&str]> (base → variant names) and BASE_OF: phf::Map<&str, &str> (variant → base)
  • shortcodes.rs - SHORTCODES: phf::Map<&str, &[&str]> (name → shortcodes + emoticons)
  • tone_groups.rs - TONE_GROUP: phf::Map<&str, u32> (base name → opaque variant-shape group id; 0/no tones is omitted)

EmojiOrderingGenerator::run additionally returns the shortcode/emoticon alias pairs so callers can feed them into a MetadataGenerator alias map - search hits :smile: without dedicated search code.

Unresolvable sequences (upstream knows emoji the family does not ship, or vice versa) are skipped: they get no ordering, group, or alternate entries.
