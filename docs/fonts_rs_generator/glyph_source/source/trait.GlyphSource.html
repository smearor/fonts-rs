Expand description

A source of glyphs for the build pipeline.

Implementations provide glyph identities (GlyphDescriptor list) and the SVG artwork for each glyph. The shared export runner turns both into GlyphEntry artifacts - metadata.json, gresource.xml, phf codegen consume them uniformly.

Two implementations exist: FontFileSource (TTF/OTF outline extraction via skrifa) and SvgDirSource (pre-rendered SVG directories).

Runs the shared export pipeline: writes each glyph’s SVG into resources_dir, then emits metadata.json and icons.gresource.xml.

Default implementation - works for every GlyphSource, whether FontFileSource or SvgDirSource.
