Module symbolic_classes 

Source
Expand description

GTK symbolic class hints for stroke-based icon sets.

GTK’s symbolic icon recoloring ignores the fill and stroke presentation attributes entirely: the painted colors are derived from symbolic classes (transparent-fill, foreground-stroke, …) or, since GTK 4.20, gtk:-namespace attributes. Elements without fill classes are filled with the foreground color, elements without stroke classes are not stroked.

Stroke-based icon sets (Lucide, Tabler outline) therefore render as solid blobs when exported under -symbolic names without class hints: their fill="none" is ignored and the foreground fill swallows the stroked details. This processor maps each shape’s effective fill/stroke (including values inherited from ancestor <svg>/<g> elements) onto the matching symbolic classes.
