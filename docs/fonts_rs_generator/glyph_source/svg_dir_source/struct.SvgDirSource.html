Expand description

GlyphSource backed by one or more directories of pre-rendered SVG files.

Iterates every svg_dir entry in registration order, resolves each file to a ParsedGlyph via the configured SvgFilenameParser, maps it to a semantic name, applies post-processing hooks, and emits the same artifacts as the TTF path via the shared GlyphSource::export runner.

Multiple directories merge into one export (e.g. an emoji set split into single-codepoint and sequence crates): name/codepoint namespaces are shared, so files across directories must partition the glyph set - a duplicate filename or resolved name collides.

pub fn pua_salt(self, salt: impl Into<String>) -> Self

Mixes salt into the CodepointStrategy::HashedPua hash input ({salt}:{raw_name}).

Use for style directories merged via CombinedSource: the default style keeps unsalted (stable) codepoints while every additional style hashes into its own namespace, so the same upstream icon cannot collide across styles.

Source

pub fn pua_allocator(self, allocator: Rc<RefCell<PuaAllocator>>) -> Self

Shares allocator with sibling sources inside a CombinedSource.

Without this, each source allocates into its own namespace: different salted inputs can still hash onto a slot another source already took, and no probing resolves across sources. Sharing the allocator gives combined sources the same linear probing a single source gets.

pub fn dir(self, svg_dir: impl Into<PathBuf>) -> Self

Adds another SVG directory to the merged export.

Directories are iterated in registration order and share the name/codepoint namespace plus the PUA allocator - use for a glyph set partitioned across directories (e.g. single-codepoint vs sequence artwork in separate resource crates).

fn resolve_codepoint( &self, parsed: &ParsedGlyph, allocator: &mut PuaAllocator, ) -> Result<Option<CodePoint>, GlyphSourceError>

Resolves the codepoint for a parsed glyph per the configured CodepointStrategy.

Multi-codepoint sequences (ZWJ emoji, keycaps) have no single codepoint - FromFilename allocates a stable PUA codepoint for them so code stays unique in the generated phf maps. The real sequence is preserved in GlyphDescriptor::sequence.

Source

fn resolve_name(&self, parsed: &ParsedGlyph) -> Option<String>

Resolves the semantic name via the configured name_resolver, falling back to the raw filename stem.

The result is kebab-normalized and, when name_prefix is set, emitted as {prefix}-{name}. Returns None when normalization yields an empty name - the glyph is then skipped.
