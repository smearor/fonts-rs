Expand description

Parses an SVG filename into a ParsedGlyph.

Returns None for files that are not glyphs (e.g. .gitkeep, license files), which are skipped silently.

Generic patterns ship as built-ins in this crate; genuinely vendor-specific formats implement this trait in their family-generator crate.
