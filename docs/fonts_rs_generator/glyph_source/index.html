Module glyph_source 

Source
Expand description

Generic glyph source abstraction for the build pipeline.

GlyphSource decouples glyph identity and artwork from the export pipeline: FontFileSource extracts outlines from TTF/OTF fonts via skrifa, SvgDirSource consumes directories of pre-rendered SVGs. Both feed the shared export runner, which emits identical artifacts (metadata.json, icons.gresource.xml, SVG files).

Pluggable seams: SvgFilenameParser for filename → glyph identity, SvgPostProcessor for artwork transformation, and CodepointStrategy for codepoint assignment.
