Set cargo:rustc-env with the absolute font path for include_bytes! in lib.rs.

Constructs the absolute path from CARGO_MANIFEST_DIR and the given relative font path, then emits a cargo:rustc-env directive so that include_bytes! can locate the font file at compile time.
