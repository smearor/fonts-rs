Expand description

Build-time extension trait for FontFamilyConfig.

Adds filesystem operations for preparing icon output directories during the build pipeline. Implemented blanketly for all T: FontFamilyConfig.

Provided Methods§

Source

fn icons_dir(output_dir: &Path) -> PathBuf

Build the icons output directory: {output_dir}/{SCALABLE_DIR}/{ICONS_CONTEXT}.

Follows the Freedesktop Icon Theme Specification used by GTK 4’s GtkIconTheme.

Source

fn prepare_icons_dir(output_dir: &Path) -> Result<PathBuf>

Prepare the icons output directory for a fresh glyph export.

Removes any existing icons directory (including stale SVGs from previous builds) and recreates it. Returns the cleaned directory path.
