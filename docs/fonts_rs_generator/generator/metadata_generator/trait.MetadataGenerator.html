Expand description

Trait for generating phf::Map metadata tables from glyph entries.

Each font family implements the data-source methods to provide keywords, categories, and aliases. The code-generation methods have default implementations that produce phf::Map Rust source code.

§Code Generation Modes

When MetadataGenerator::deduplicate_statics returns true, the generated code extracts repeated value lists into static constants (e.g. static KW_0: &[GlyphKeyword] = &[...]) and references them from the phf::Map. This reduces binary size for large maps with many duplicate keyword or category lists.

When it returns false (the default), values are inlined directly in the phf::Map entries.

Source

fn aliases(&self) -> Vec<(String, String)>

Returns all aliases as (alias, canonical) pairs.

Default implementation returns an empty vec (no aliases).

Source

fn deduplicate_statics() -> bool

Whether to extract repeated value lists into static constants.

Override to return true for large maps with many duplicate value lists (e.g. nerd-fonts with thousands of icons sharing categories). Default is false (inline values directly).
