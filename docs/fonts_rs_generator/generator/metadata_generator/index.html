Generic metadata generator trait for build-time phf::Map code generation.

Provides MetadataGenerator — a trait for generating phf::Map constants for keywords, categories, and aliases from glyph metadata. Each font family implements the data-source methods (keywords_for, categories_for, aliases); the code-generation methods (generate_keywords, generate_categories, generate_aliases, run) are provided by default.

The MetadataGenerator::deduplicate_statics hook controls whether generated phf::Map entries reference shared static constants (for large maps with many duplicate value lists) or inline the values directly.
