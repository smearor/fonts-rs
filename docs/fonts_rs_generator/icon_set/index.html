Custom icon sets - TOML-driven glyph subsets for applications.

An application declares a minimal icon set in a root-level icons.toml and invokes IconSetBuild from its build.rs:

ⓘ
fn main() -> miette::Result<()> {
    fonts_rs_generator::IconSetBuild::from_file("icons.toml")?.run()?;
    Ok(())
}

The build reads the [IconSetSpec] (defined in fonts-rs-model - the schema is shared with authoring tools), resolves each [[iconset.sources]] table via IconSetSourceResolver, merges the whitelisted glyphs through CombinedSource, and generates the complete iconset.rs module via IconSetModuleGenerator.

See concepts/planned/CUSTOM_ICON_SET.md for the design.
