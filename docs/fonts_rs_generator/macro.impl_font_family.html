Expand description

Generates the runtime font family API for a marker type.

§Invocation

ⓘ
fonts_rs_generator::impl_font_family!(
    Code39,
    Code39Definition,
    glyphs = codepoint_map::GLYPHS,
    reverse = codepoint_map::REVERSE_GLYPHS,
    name = Code39Name,
    css_font_family = "LibreBarcode39", // optional
    capabilities = [icon_theme, pango, html],
);

css_font_family is optional: it overrides FontFamily::CSS_FONT_FAMILY when the TTF’s family name differs from FAMILY_DISPLAY_NAME.

§Emitted items

  • impl FontFamilyConfig for $marker - delegates all constants to $definition.
  • impl FontFamily for $marker - type Name = $name, glyph lookups via the $glyphs (phf::Map<char, &'static str>) and $reverse (phf::Map<&'static str, char>) maps.
  • One empty impl per declared capability - all capability methods are trait defaults. Valid capabilities: icon_theme (IconThemeFont), pango (PangoFont), html (HtmlExport).
  • Inherent forwarding methods for every declared capability plus install()/ensure_registered(), so concrete call sites need no trait import.

Capability impls and forwarders are #[cfg(feature = "gtk")]-gated; the core impl is feature-free. SoftwareRender is not a capability here - it is emitted by impl_font_loader!.
