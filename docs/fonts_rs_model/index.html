Generic model types for font glyph packaging.

Provides font-family-agnostic types shared across all fonts-rs-* crates: CodePoint, ResourcePath, FontFamilyMarker marker trait, GlyphName phantom-typed newtype, and GlyphEntry generic metadata.

The high-level runtime API is the FontFamily core trait plus the capability traits IconThemeFont, PangoFont, HtmlExport, and SoftwareRender - see prelude for a one-line import.

These types are extracted from nerd-fonts-model and generalized so that any font family crate can use them without Nerd Font dependencies.
