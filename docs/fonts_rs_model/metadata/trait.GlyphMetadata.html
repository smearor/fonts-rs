Expand description

Metadata registry for a font family.

Each font family crate implements this trait with its build-time generated static maps, providing unified keyword, category, and search access.

§Examples

ⓘ
pub struct NotoEmojiMetadata;

impl GlyphMetadata for NotoEmojiMetadata {
    fn keyword_map(&self) -> &GlyphKeywordMap { &KEYWORDS }
    fn category_map(&self) -> &GlyphCategoryMap { &CATEGORIES }
}

fn search(&self, query: &str) -> Vec<&'static str>

Search glyphs by keyword, category, alias, or name.

Performs a case-insensitive substring match against glyph names, keywords, categories, and aliases. Returns matching glyph names sorted alphabetically.
