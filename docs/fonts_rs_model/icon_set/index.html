Module icon_set 

Source
Expand description

Serde model for application-defined custom icon sets (icons.toml).

These types are the wire format shared between the build-time generator (fonts_rs_generator::IconSetBuild reads icons.toml) and authoring tools like the icon-set builder (which writes it). All types derive Serialize and Deserialize; validation is pure data — filesystem-dependent checks stay in the generator.
