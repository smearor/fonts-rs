Expand description

Maps a family’s exported icon name (lucide-check-symbolic) back to its upstream source - the resources/svg subdirectory, file stem and default post-processors, bundled as UpstreamIcon.

Icon-capable families implement this next to their impl_font_family! invocation. The default path covers flat single-style families (ICON_PREFIX + -symbolic stripping); multi-style families override upstream_icon for per-stem routing (Eva fill/outline, Fluent regular-24/filled-24, Heroicons micro/mini/solid).

fn upstream_stem(icon_name: &str) -> Option<&str>

Strips ICON_PREFIX and -symbolic from an exported icon name - the shared first step of every reverse mapping. Returns None for names outside the family’s convention.

Source

fn upstream_icon(icon_name: &str) -> Option<UpstreamIcon>

Reverse-maps a displayed icon name to its upstream location. None for non-conforming names - callers must skip rather than emit a wrong stem (a wrong name surfaces as UnknownIcon in IconSetBuild).
