Expand description

Builder for self-contained HTML export pages.

Created via HtmlSvgExport::html; covers both HTML examples: render_font_face() (the css_class_html example, HtmlExport families only) and render() (the svg_html example, any family with glyph SVGs).

F is a ZST marker - the builder stores no F value, so PhantomData<fn() -> F> keeps the parameter used (covariant, no ownership/drop semantics).
