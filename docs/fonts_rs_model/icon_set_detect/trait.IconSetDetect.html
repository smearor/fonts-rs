Expand description

Prefix-based icon set detection for a font family.

Implemented by families whose icon namespace aggregates multiple upstream sets. The associated Set type is the family-specific set enumeration (e.g. IconSet for Nerd Fonts).

The detection result is also the natural implementation of FontFamilyConfig::is_valid_icon_name: a name is valid when it resolves to a known set.
