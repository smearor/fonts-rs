Expand description

Software rendering via ab_glyph (feature render).

Emitted per family by impl_font_loader! - the font loading itself stays per-crate because the TTF source differs (embed-fonts vs. resources/ directory).

Required Associated Types§

type Variant: Copy + Default

Variant selector - () for single-font families, a per-family enum for multi-TTF families (e.g. NerdFontVariant).

Required Methods§

fn ab_glyph(variant: Self::Variant) -> Option<&'static FontVec>

Returns the cached ab_glyph font for variant.

With embed-fonts the TTF is compiled into the binary; otherwise it is loaded from resources/ relative to the working directory.

Provided Methods§

fn font() -> Option<&'static FontVec>

Convenience: the default variant. For single-font families this is the only call needed (Code39::font()).

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
