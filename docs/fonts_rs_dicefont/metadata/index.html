Glyph metadata: die-type categories and d6 style ordering.

Provides category lookup for Dicefont glyphs, grouping each die face by its die type: dicefont-d20-4 -> “d20”, dicefont-dot-d6-2 -> “d6”. The dotted d6 variants keep their “d6” category - they are six-sided dice. The Fudge dice (dicefont-f, dicefont-f-*) land in “fudge”.

Categories are generated at build time from the glyph names - Dicefont ships no upstream keyword, category, or alias source, so the keyword and alias maps stay empty.

GlyphOrdering treats dicefont-solid-small-dot-d6-{face} as the base d6 style and links the other three d6 styles (d6-{face}, dot-d6-{face}, small-dot-d6-{face}) onto it - the link powers the detail sidebar’s Variants section, sorts each variant next to its base, and collapses the variants behind the base in the browse grid.

This module is only available when the metadata feature is enabled.
